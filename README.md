# Rede Âmago

Site institucional estático em português para a Rede Âmago, com identidade visual baseada na marca pública, apresentação de atendimentos e unidades, perguntas frequentes e diretório filtrável de profissionais.

## Executar localmente

Abra `index.html` no navegador ou sirva esta pasta com qualquer servidor de arquivos estáticos.

## Personalização

- Conteúdo e estrutura: `index.html`
- Estilos responsivos: `styles.css`
- Menu, filtros e links de contato: `script.js`
- Dados dos profissionais: `profissionais.json`
- Páginas individuais: `profissionais/` (geradas por `node build-professional-pages.mjs`)
- Logo e retratos: `assets/`

A logo e as fotos foram obtidas dos perfis públicos da Rede Âmago. Os nomes, abordagens e informações de atendimento seguem como aparecem nesses perfis; confirme horários e disponibilidade diretamente com a equipe. O contato comercial publicado é (62) 98288-1000.
